# ☕ Café Grão Real

**Café Grão Real** é um projeto de desenvolvimento web que apresenta o site institucional de uma cafeteria fictícia, com uma identidade visual elegante e acolhedora. O objetivo é apresentar a marca, destacar seus produtos e proporcionar uma experiência visual agradável aos visitantes.

## 📌 Sobre o projeto

O site foi desenvolvido utilizando HTML5 e CSS3, aplicando conceitos de estruturação de páginas, estilização, organização de conteúdo e design responsivo.

A proposta é representar uma cafeteria especializada em cafés selecionados, oferecendo aos visitantes informações sobre sua essência e seus principais produtos.

## ✨ Funcionalidades

- **Página inicial:** apresentação da cafeteria com título e descrição.
- **Seção Nossa Essência:** apresenta a história, a proposta e os diferenciais da cafeteria.
- **Cardápio:** exibe os produtos em destaque, com nomes, preços e descrições.
- **Cards de produtos:** organização visual dos produtos em cartões individuais.
- **Efeitos visuais:** animação de destaque ao passar o mouse sobre os produtos.
- **Layout responsivo:** organização dos produtos em grade adaptável a diferentes larguras de tela.
- **Rodapé:** identificação e direitos reservados da cafeteria.

## 🛠️ Tecnologias utilizadas

As seguintes tecnologias foram utilizadas no desenvolvimento:

- HTML5 – estruturação e organização do conteúdo.
- CSS3 – estilização, cores, espaçamentos, efeitos e layout responsivo.

## 🎨 Identidade visual

O projeto utiliza uma paleta de cores inspirada no universo do café, transmitindo sofisticação, conforto e aconchego.

- Marrom escuro: `#3d2514`
- Dourado: `#bf8f54`
- Fundo claro: `#fbf9f6`
- Cor do texto: `#4a4a4a`

O layout utiliza cartões com bordas arredondadas, sombras suaves e efeitos de interação para proporcionar uma navegação agradável.

## 🚀 Como executar o projeto

Não é necessário instalar programas ou dependências adicionais.

1. Faça o download ou clone este repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Abra a pasta do projeto.
3. Localize o arquivo `cafeteria.html`.
4. Abra o arquivo em qualquer navegador de internet.

**Observação:** mantenha os arquivos `cafeteria.html` e `cafeteria.css` na mesma pasta para garantir o carregamento correto dos estilos.
